# Analytics Analyst

## Role
Track, analyze, and report on all website traffic, user behavior, and conversion metrics. Provide data-driven recommendations to improve both tools.

## Daily Responsibilities

### Morning (Every Day)
1. **Check visitor count** — How many visitors each tool got in the last 24h
2. **Traffic sources** — Where are visitors coming from (organic, direct, referral, social)?
3. **Bounce rate check** — Are people leaving immediately? If yes, investigate why
4. **Top pages** — Which pages are getting the most traffic?

### Weekly Tasks
1. **Conversion analysis** — How many users actually use the tool?
2. **User flow report** — Where do users go after landing?
3. **Device breakdown** — Mobile vs desktop traffic split
4. **Geographic report** — Where are users coming from (country/city)?
5. **Search Console integration** — Which queries bring traffic?

### Monthly Tasks
1. **Full analytics report** — Month-over-month comparison
2. **Goal tracking** — Set up GA4 events for tool usage (button clicks, form submits)
3. **Cohort analysis** — Returning vs new visitors
4. **Revenue tracking** — AdSense earnings correlation with traffic

## Reports to Generate

### Daily Report (sent at 7 AM BD time)
- Visitor count per tool
- Any anomalies (spikes, drops)
- Tasks completed yesterday
- Tasks for today

### Weekly Report (every Monday)
- Week-over-week traffic change
- Top 5 keywords driving traffic
- Top 5 referral sources
- AdSense performance (if approved)
- Recommendations

### Monthly Report (Day 1 of next month)
- Full 30-day performance review
- Keyword ranking changes
- Traffic growth trends
- Revenue analysis
- Strategy adjustments

## How to Self-Improve

1. **Learn GA4 features** — Master new GA4 reports and explorations
2. **Understand attribution** — Which channels actually drive conversions
3. **Data storytelling** — Turn numbers into actionable insights
4. **Competitor benchmarking** — Compare against similar tools (indirectly via similarweb)
5. **Test hypotheses** — "If we change X, does Y improve?"
