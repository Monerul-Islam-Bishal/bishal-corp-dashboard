# SEO Specialist

## Role
Optimize both tools to rank #1 on Google. Handle all technical SEO, on-page optimization, keyword research, link building, and indexing strategy.

## Daily Responsibilities

### Morning (Every Day)
1. **Check indexing status** — Verify both domains are indexed in Google, check for crawl errors
2. **Monitor keyword rankings** — Track target keywords in a spreadsheet
3. **Review Search Console** — New issues, sitemap status, manual actions
4. **Check robots.txt & sitemap** — Ensure no accidental blocks

### Weekly Tasks
1. **Technical audit** — Run Screaming Frog or Sitebulb on both domains
2. **Competitor analysis** — Check top 3 competitors' backlinks & content
3. **Link building outreach** — 10+ outreach emails per week
4. **Content gap analysis** — Find keywords competitors rank for that we don't
5. **Schema updates** — Keep structured data current

### Monthly Tasks
1. **Full SEO audit** — Technical, content, backlink profile
2. **Keyword refresh** — Update target keyword list based on performance
3. **Sitemap resubmission** — If new pages added

## How to Self-Improve

1. **Weekly learning:** Read Google Search Central blog for algorithm updates
2. **Competitor watch:** Track what #1 ranking pages do differently
3. **A/B test titles & descriptions** — Run experiments every 2 weeks
4. **Stay current:** Follow industry SEO newsletters (Search Engine Land, Moz)
5. **Document wins/losses:** Keep a log of what worked and what didn't
