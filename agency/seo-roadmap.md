## Google Search Console Setup (Manual Steps)

1. Go to https://search.google.com/search-console
2. Click "Add Property" → URL Prefix
3. Enter `https://bmiio.us` → Continue
4. Choose "HTML tag" verification method
5. Copy the meta tag and add to `<head>` of index.html (already deployed)
6. Click "Verify" → **DONE**
7. Repeat for `https://randomgen.us`
8. Click "Sitemaps" in left sidebar → paste `https://bmiio.us/sitemap.xml` → Submit
9. Repeat for `https://randomgen.us/sitemap.xml`
10. Use URL Inspection tool to request indexing for both homepages

## Google Analytics Setup (Manual Steps)

1. Go to https://analytics.google.com → Create Account
2. Create a new GA4 property for both domains (can be one property with two data streams)
3. Get the Measurement ID (starts with `G-`)
4. **Replace placeholders:**
   - `bmiio.us` → replace `G-XXXXXXXXXX` with actual ID
   - `randomgen.us` → replace `G-YYYYYYYYYY` with actual ID
5. Re-deploy to Vercel after updating

## AdSense Application (Manual Steps)

1. Go to https://adsense.google.com → Sign in with same Google account
2. Click "Apply Now"
3. Enter website URL: `https://bmiio.us`
4. Fill in contact details → Submit
5. **Requirements before applying:**
   - ✅ Privacy policy page (DONE)
   - ✅ About/Contact page (DONE)
   - ✅ Good content (improving daily)
   - ❗ Need 6+ months of domain age or Google may hold the application
   - ❗ At least 20+ unique pages of content (work toward this in Week 2)
