# Daily Marketing Checklist

## Morning (7 AM BD / 1 AM UTC)
- [ ] Check if both domains are online
- [ ] Run PageSpeed Insights for both tools
- [ ] Check Google Search Console for new issues
- [ ] Review yesterday's analytics (visitors, sources)
- [ ] Check keyword ranking progress
- [ ] Review AdSense application status

## Midday
- [ ] Write or improve content (1 piece per day)
- [ ] Outreach for backlinks (5+ emails)
- [ ] Share tool on one social platform
- [ ] Check for broken links
- [ ] Monitor any new "People Also Ask" questions

## Evening
- [ ] Log today's metrics in tool-stats files
- [ ] Write daily report
- [ ] Review mistakes/improvements
- [ ] Plan tomorrow's tasks
- [ ] Update roadmap progress
